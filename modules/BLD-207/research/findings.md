## Claims by source

### S-01 - Glean Partner Competency Program Guide

- `C-06` Each of the 5 competency agents must implement at least 3 discrete steps beyond simple retrieval, including at least one thinking or transformation step.
- `C-07` Each of the 5 competency agents must configure retrieval guardrails so the agent uses a well-defined set of content sources and has clear instructions for what it can and cannot answer.
- `C-08` Each of the 5 competency agents must contain explicit error-handling with a defined fallback behavior for low-confidence or out-of-scope questions.
- `C-09` At least 1 of the 5 competency agents must invoke actions or tools that write to other systems.
- `C-27` Competency graduates understand best practices for testing and validation of Glean agents.

### S-02 - Partner Enablement: Glean Agent Building - plan, launch, deploy, measure

- `C-37` For each priority agent, assign a project lead and supporting experts, document the current process including baseline performance numbers, design the future-state process with expected improvements, and build an implementation plan covering scope, key dates, success measures, and security and data compliance checks.
- `C-39` The build phase translates the approved design into an agent architecture map, implements the agent in the Glean platform following best practices, executes comprehensive testing and refinement cycles, and secures formal owner sign-off before launch.
- `C-45` Measurement compares actual outcomes against the KPIs and success criteria defined during planning, using both quantitative data and qualitative feedback.
- `C-46` Usage analytics should track the number of agent runs, count of distinct users, frequency of use, and patterns of engagement over time.
- `C-47` High abandonment rates or declining usage can indicate user friction or changing needs.
- `C-48` Measurement insights feed directly back into planning to create a continuous improvement cycle, and successful agents become templates for future development.

### S-05 - Partner Accreditation & Competency Roadmap - Module Tracker

- `C-94` BLD-207 covers how to evaluate prompts and agents, measure quality, and prevent regressions.
