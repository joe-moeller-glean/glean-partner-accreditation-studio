## Claims by source

### S-03 - Partner Enablement Deck: MCP, Custom Actions, and Skills

- `C-49` The mental model is: skills are reusable instructions, templates, and domain expertise; actions are tool calls that read from or write to systems; MCP is an open protocol for exposing tools and data to AI apps and agents; and agents are the governed workflow wrapper that packages skills, tools, and knowledge together.
- `C-67` Skills standardize reasoning, actions standardize execution, MCP standardizes interoperability, and agents operationalize all three into production workflows.

### S-05 - Partner Accreditation & Competency Roadmap - Module Tracker

- `C-90` BLD-101 introduces what can be built with agents, actions, APIs, and integration points.
- `C-91` BLD-102 explains actions, MCP, architecture choices, and when to use each approach.

### S-08 - [EXT] Glean Partner Program Guide 2026

- `C-109` Partners differentiate their business with custom agents, connectors, and embedded experiences that create reusable IP and higher-margin offerings.
- `C-110` Technology partners build on Glean's open, extensible platform using APIs, MCP-based tools, embedded experiences, agent extensions, and the connector framework.
- `C-111` The Glean platform spans Search, Assistant, and Agents.
