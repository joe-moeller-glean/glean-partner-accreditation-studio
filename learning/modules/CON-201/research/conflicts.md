# CON-201 - conflicts, exclusions, and open questions

## Authority ruling

Current Glean product and developer documentation (tier 1) is authoritative for product behavior. Partner enablement and program documents (tier 2) supply program rules and practice guidance that tier 1 does not contradict. Tier 3 and 4 material is excluded.

## Open questions carried by this module

- U7: whether a later successful bulk upload inherits or clears a 7-day stale-deletion pause is undocumented; the module does not depend on it.
- U6: internal sources describe dynamic deletion thresholds for native crawls; the module teaches only the public 20% / 7-day rule.
