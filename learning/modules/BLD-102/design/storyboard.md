## 3. SCR-03 - A3 - Definitions
**Four words, four meanings**

Skills are reusable instructions, templates, and domain expertise. Actions are tool calls that read from or write to systems. MCP is an open protocol for exposing tools and data to AI apps and agents. Agents are the governed workflow wrapper.
