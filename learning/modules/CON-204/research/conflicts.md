# CON-204 - conflicts, exclusions, and open questions

## Authority ruling

Current Glean product and developer documentation (tier 1) is authoritative for product behavior. Partner enablement and program documents (tier 2) supply program rules and practice guidance that tier 1 does not contradict. Tier 3 and 4 material is excluded.

## Open questions carried by this module

- SDK basis is glean-indexing-sdk v1.2.0 (C-220). Re-verify class names, options, and CLI verbs each release.
- U-204-1: import paths for model classes are not taught; learners follow the installed version's reference.
- Lab fixture (OD-5) must exist before learners run the build lab.
