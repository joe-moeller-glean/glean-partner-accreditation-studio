## Claims by source

### S-03 - Partner Enablement Deck: MCP, Custom Actions, and Skills

- `C-49` The mental model is: skills are reusable instructions, templates, and domain expertise; actions are tool calls that read from or write to systems; MCP is an open protocol for exposing tools and data to AI apps and agents; and agents are the governed workflow wrapper that packages skills, tools, and knowledge together.
- `C-50` Use skills when you need repeatable methodology, domain expertise, or consistent reasoning.
- `C-51` Use custom actions when you need deterministic execution against an internal API, legacy system, or proprietary workflow.
- `C-52` Use MCP when you want open-standard interoperability and reusable tool access across ecosystems.
- `C-53` Use agents when you need scheduled, event-driven, or governed end-to-end workflows.
- `C-64` Skills are reusable packages of instructions, templates, and tools that teach Assistant how to execute specific tasks with domain expertise, and they are loaded only when relevant.
- `C-67` Skills standardize reasoning, actions standardize execution, MCP standardizes interoperability, and agents operationalize all three into production workflows.
