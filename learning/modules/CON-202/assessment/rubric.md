# CON-202 assessment rubric

Mastery score: 80%. Items are single-select with explanatory feedback on every option.

## Objective coverage

| Objective | Items |
|---|---|
| `OBJ-01` Run structured discovery with the custom connector questionnaire and record evidence, not assumptions. | Q-01, Q-02 |
| `OBJ-02` Assess feasibility for content, permissions, people, and activity, and state the cost of each gap. | Q-03, Q-04 |
| `OBJ-03` Size a crawl against source and Glean rate limits. | Q-05, Q-06 |
| `OBJ-04` Choose an identity strategy and a hosting model with the customer. | Q-07, Q-08 |
| `OBJ-05` Build a risk register and make a conditional go or no-go call. | Q-09, Q-10 |

## Item-writing rules applied

- Every item tests a claim-backed fact or a decision derived from one, never wording recall.
- Distractors are plausible partner mistakes drawn from the source material, not absurd options.
- Feedback explains why an option is wrong, not merely that it is wrong.
- Answer keys live in `key.json` and are never present in `items.json`.

## Calibration

Review live pass rates after 30 completions. Flag any item below 30% or above 95% for rewrite.
