# CON-203 - conflicts, exclusions, and open questions

## Authority ruling

Current Glean product and developer documentation (tier 1) is authoritative for product behavior. Partner enablement and program documents (tier 2) supply program rules and practice guidance that tier 1 does not contradict. Tier 3 and 4 material is excluded.

## Open questions carried by this module

- U-203-1: canonical wire type for document timestamps in the raw API; the module teaches epoch seconds, as the SDK requires.
- U-203-2: rate limits for bulk, delete, and permission-update endpoints are not in the reviewed sources; the module states only documented limits.
- Lab fixture (OD-5): the policy wiki mock API and disposable test datasources must exist before learners run the lab.
