## 1. Narrative frame

- **Recurring persona:** Ravi's technical consultant on a live escalation
- **Through-line situation:** An agent returns a wrong answer and the customer wants root cause today
- **Cold open (A1) hook:** The agent cited a document the user cannot access. Either permissions are broken or the trace will show something else entirely.
- **Signature moment (one T3 reveal):** The trace resolves: the failing step isolates and the root cause becomes unambiguous

## 2. Learning outcomes (observable)

- `OBJ-01` — Read an agent execution trace and identify the failing step
- `OBJ-02` — Distinguish a retrieval problem from a tool, permission, or prompt problem
- `OBJ-03` — Reproduce a defect reliably
- `OBJ-04` — Assemble a clean escalation package for Glean

## 5. Interactions

- **`INT-TRACE`** — Two trace-reading exercises; the second isolates the failing step - the signature moment.
- **`INT-SORT`** — Symptoms classified by subsystem.
- **`INT-SIM`** — Reproduction walkthrough.
- **`INT-FADE`** — Escalation package assembly.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.

## 6. Assessment plan

- **Format:** Lab (tracker: `Lab`)
- **Blueprint:** Verifiable end state: correct root-cause identification from a trace, a reliable reproduction, and a complete escalation package. Rubric-scored.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: blaming retrieval for a permission outcome, escalating without reproduction, package missing timestamps or user context.
