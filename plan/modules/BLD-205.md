## 1. Narrative frame

- **Recurring persona:** Alex with Northwind's data engineer
- **Through-line situation:** Analytics data lives in Snowflake and the agent needs it live
- **Cold open (A1) hook:** Indexing the warehouse would take a week and be stale by Tuesday. There is a better answer.
- **Signature moment (one T3 reveal):** The integration returns live warehouse data inside an agent run

## 2. Learning outcomes (observable)

- `OBJ-01` — Choose between indexing and live-querying warehouse data
- `OBJ-02` — Implement a Snowflake-backed integration for an agent workflow
- `OBJ-03` — Handle authentication, scoping, and cost implications of live queries
- `OBJ-04` — Validate results and define freshness expectations with the customer

## 5. Interactions

- **`INT-SIM`** — Three lab sequences: connect, scope, call from an agent.
- **`INT-COMPARE`** — Index-versus-live-query for warehouse data.
- **`INT-CHECKLIST`** — Environment check and the integration checklist including a customer freshness agreement.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.

## 6. Assessment plan

- **Format:** Lab (tracker: `Lab`)
- **Blueprint:** Verifiable end state: authenticated warehouse integration returning scoped live results inside an agent run, with a documented freshness and cost note. Rubric-scored.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: unscoped queries, ignoring cost, promising real-time without defining it.

## 7. Job aid / carry-away

- Warehouse integration checklist with the freshness agreement template.

## 8. Claims to establish and verify

- Current supported integration mechanism for Snowflake-backed data - tier-1 docs
- Authentication and scoping options
- Any cost or latency statement requires an anchor or is framed as customer-dependent

Freshness window: 90 days (product capability).. Every factual sentence carries a `claim_id` resolving to `sources.json`.
