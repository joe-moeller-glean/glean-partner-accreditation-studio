## 6. Assessment plan

- **Format:** Design review, rubric-scored (tracker: `Design review`)
- **Blueprint:** Learner submits an integration design: chosen pattern, auth approach, UX boundary, effort estimate with assumptions, and one named risk.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: choosing the Web SDK for a server-side need, ignoring auth complexity, estimating without assumptions.
