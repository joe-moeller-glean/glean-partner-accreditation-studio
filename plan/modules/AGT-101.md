## Why this module exists

The existing agents path opens at 200 level (`FND-104`) and assumes the learner already has platform
vocabulary. There is no 100-level agents entry point. `AGT-101` is that entry point: it answers "what
*is* a Glean agent, how is it different from the other things Glean can do, and what is it made of"
before any build tooling appears.

## Learner promise

After this module a partner can define a Glean agent in one sentence, choose correctly between a
skill, an action, MCP, and an agent for a given request, name the six parts of an agent, explain what
triggers a run, describe the guardrails and fallback every production agent needs, and place agent
work inside the plan → build → measure lifecycle.
