## 1. Narrative frame

- **Recurring persona:** Alex, whose agent worked last month
- **Through-line situation:** A prompt change improved one answer and silently broke four others
- **Cold open (A1) hook:** One prompt improvement. One better answer. Four regressions nobody noticed for three weeks.
- **Signature moment (one T3 reveal):** The evaluation harness runs and the regression surfaces immediately

## 2. Learning outcomes (observable)

- `OBJ-01` — Design an evaluation set that represents real usage
- `OBJ-02` — Measure agent and prompt quality with repeatable criteria
- `OBJ-03` — Detect regressions before they reach users
- `OBJ-04` — Establish a testing cadence for a production agent

## 5. Interactions

- **`INT-FADE`** — Evaluation set construction, worked then independent.
- **`INT-TRACE`** — Read harness results and identify the regression - the signature moment.
- **`INT-SORT`** — Classify result deltas as regression, variance, or genuine improvement.
- **`INT-BRANCH`** — Ship-or-hold decision with consequences for user trust.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.

## 6. Assessment plan

- **Format:** Lab (tracker: `Lab`)
- **Blueprint:** Verifiable end state: an evaluation set, documented criteria, a completed run, a correctly identified regression, and a testing cadence proposal. Rubric-scored.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: evaluating on happy-path cases only, treating variance as regression, shipping on a single improved case.

## 7. Job aid / carry-away

- Evaluation toolkit: set template, criteria sheet, pass bar, and cadence.
