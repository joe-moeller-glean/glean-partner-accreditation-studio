## 1. Narrative frame

- **Recurring persona:** Sam with Northwind's data team
- **Through-line situation:** Structured data exists but agents keep answering from the wrong table
- **Cold open (A1) hook:** The answer is in the warehouse. The agent keeps quoting a deprecated spreadsheet instead.
- **Signature moment (one T3 reveal):** Semantic layer resolves: ambiguous sources collapse to one authoritative definition

## 2. Learning outcomes (observable)

- `OBJ-01` — Explain how structured data and semantics affect retrieval and grounding quality
- `OBJ-02` — Choose between indexing structured data and querying it live
- `OBJ-03` — Define governance for authoritative definitions and deprecated sources
- `OBJ-04` — Recommend a structured-data approach for a given customer situation

## 5. Interactions

- **`INT-SORT`** — Classify sources as authoritative or deprecated - the signature resolve collapses ambiguity.
- **`INT-COMPARE`** — Index-versus-live-query trade-offs.
- **`INT-BRANCH`** — Warehouse-or-index recommendation with consequences for freshness and cost.
- **`INT-HOTSPOT`** — Semantic attachment points.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.
