## 1. Narrative frame

- **Recurring persona:** Alex, choosing between an action and an MCP server
- **Through-line situation:** Northwind needs live inventory data inside an agent and there are two ways to get it
- **Cold open (A1) hook:** Two implementations, same outcome. One takes a day and one takes three weeks. The difference is a question Alex has not asked yet.
- **Signature moment (one T3 reveal):** Architecture choice resolves: the same workflow rendered both ways, with cost and constraint made visible

## 2. Learning outcomes (observable)

- `OBJ-01` — Explain what actions and MCP each provide and how they differ architecturally
- `OBJ-02` — Choose between an action and an MCP integration for a given requirement
- `OBJ-03` — Describe the authentication and governance implications of each approach
- `OBJ-04` — Identify what makes a tool reliable enough for production use
