- **`INT-COMPARE`** — Index-versus-live-query for lakehouse data.
- **`INT-CHECKLIST`** — Environment check and integration checklist.

## 6. Assessment plan

- **Format:** Lab (tracker: `Lab`)
- **Blueprint:** Verifiable end state: authenticated lakehouse integration returning scoped live results inside an agent run, with a documented freshness and cost note. Rubric-scored.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: copying the warehouse auth pattern without adaptation, unscoped queries, undefined freshness.

## 7. Job aid / carry-away

- Lakehouse integration checklist plus a diff sheet against the warehouse pattern.

## 8. Claims to establish and verify

- Current supported integration mechanism for Databricks-backed data - tier-1 docs
- Authentication and scoping differences from the warehouse pattern
