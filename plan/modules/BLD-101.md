**Execution mode:** Full build — all 14 phases

## 1. Narrative frame

- **Recurring persona:** Alex, partner builder
- **Through-line situation:** Northwind asks 'what can you actually build for us?' and Alex needs a real answer, not a capability list
- **Cold open (A1) hook:** Northwind hands Alex five requests. Alex can build four of them today, one of them differently than asked, and needs to say which is which in the meeting.
- **Signature moment (one T3 reveal):** Build surface map assembles: agents, actions, APIs, and integration points each light with a real example

## 2. Learning outcomes (observable)

- `OBJ-01` — Describe what can be built with agents, actions, APIs, and integration points
- `OBJ-02` — Match a customer request to the build surface that fits it
- `OBJ-03` — Identify the boundary where a request needs a connector or a custom integration
- `OBJ-04` — Scope a first build that proves value in days rather than weeks

## 5. Interactions

- **`INT-SORT`** — Five requests matched to build surfaces; feedback names the deciding characteristic.
- **`INT-SIM`** — One real agent walked end to end over captures.
- **`INT-COMPARE`** — Action versus connector boundary.
- **`INT-BRANCH`** — First-build scoping with consequences for time to value.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.

## 6. Assessment plan

- **Format:** Quiz, 8 items (tracker: `Quiz`)
- **Blueprint:** OBJ-01 x2, OBJ-02 x3, OBJ-03 x2, OBJ-04 x1.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Defaulting to a custom connector, assuming agents can act without configured tools, assuming APIs are required for embedded experiences.

## 7. Job aid / carry-away

## 8. Claims to establish and verify

- Current build surfaces and their real capability boundaries
- Agent composition: tools, steps, memory, triggers
- The precise boundary where an action is insufficient and a connector is required
- Tracker note says this asset 'needs to be built' and the source inventory lists the resource as TBD - research must establish the baseline

Freshness window: 90 days (product capability).. Every factual sentence carries a `claim_id` resolving to `sources.json`.
