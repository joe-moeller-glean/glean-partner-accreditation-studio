## 1. Narrative frame

- **Recurring persona:** Sam, in Northwind's security review
- **Through-line situation:** Northwind's CISO wants to know what stops an agent from doing something harmful
- **Cold open (A1) hook:** The CISO's question is not 'is it encrypted'. It is: 'what stops your agent from emailing our salary data to the wrong person?'
- **Signature moment (one T3 reveal):** Control layers assemble around a single agent action, each layer named as it lands

## 2. Learning outcomes (observable)

- `OBJ-01` — Explain the security model across identity, permissions, data handling, and agent guardrails
- `OBJ-02` — Describe what Protect+ adds and when a customer needs it
- `OBJ-03` — Answer the top security-review questions accurately and within scope
- `OBJ-04` — Recognize which security questions require escalation to Glean

## 6. Assessment plan

- **Format:** Knowledge check, 6 items (tracker: `Knowledge check`)
- **Blueprint:** OBJ-01 x2, OBJ-02 x2, OBJ-03 x1, OBJ-04 x1 (escalation judgment).

## 8. Claims to establish and verify

- Current security controls, identity model, and data-handling behavior (90-day window, tier 1/2 required)
- Protect+ scope and what it specifically adds - must not be overstated
- Agent guardrail mechanisms and their configurability
- Trust-portal document availability and what is under NDA
- Existing SCORM folder 'Glean Architecture/Security Module' - inventory before authoring

Freshness window: 90 days (security posture) - the tightest window in the portfolio.. Every factual sentence carries a `claim_id` resolving to `sources.json`.

## 9. Risks, blockers, and SME questions

- Highest-consequence factual module: a wrong security statement damages customer trust and partner credibility. Zero tolerance for unanchored claims.
- Four separate sources listed (Security Enablement, Security & Protect+, Protect+ Setup Best Practices, Architecture/Security SCORM) - research must reconcile them and label superseded material.
- NDA-classified source content; confirm what may appear in a partner-facing SCORM package before release.
- No owner - `needs_sme`; this needs a named security SME, not a general reviewer.
