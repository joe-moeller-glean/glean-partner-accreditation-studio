## 5. Interactions

- **`INT-HOTSPOT`** — Architecture layers and permission stages open labelled panels; every label traces to a claim_id. Text-equivalent table is keyboard reachable.
- **`INT-SIM`** — Three guided walkthroughs over real captures - search, assistant, agents. Each step <=35 words, state persisted.
- **`INT-REVEAL`** — Myth/reality pairs correcting the 'AI sees everything' misconception.
- **`INT-CHECK`** — Learner selects the strongest one-minute framing for a named audience; feedback explains the reasoning.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.
