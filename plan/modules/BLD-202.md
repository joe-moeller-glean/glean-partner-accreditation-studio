## 1. Narrative frame

- **Recurring persona:** Alex, building a connector end to end
- **Through-line situation:** Requirements to tested handoff in one lab
- **Cold open (A1) hook:** Requirements to production handoff. The lab is not done when the data appears - it is done when someone else can maintain it.
- **Signature moment (one T3 reveal):** The connector completes a validated crawl and the handoff package is complete

## 2. Learning outcomes (observable)

- `OBJ-01` — Implement a connector from documented requirements
- `OBJ-02` — Test authentication, pagination, permissions, and failure recovery
- `OBJ-03` — Validate indexed content against the source
- `OBJ-04` — Produce a maintainable handoff package

## 5. Interactions

- **`INT-SIM`** — Five lab sequences from auth to failure recovery; step state persisted.
- **`INT-TRACE`** — Validate indexed content against the source and identify discrepancies.
- **`INT-SORT`** — Tests matched to what each actually proves.
- **`INT-CHECKLIST`** — Environment check and handoff package.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.

## 6. Assessment plan

- **Format:** Lab (tracker: `Lab`)
- **Blueprint:** Verifiable end state: working connector, passing test set (auth, pagination, permissions, recovery), validated content, complete handoff package. Rubric-scored.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: declaring success on first fetch, skipping permission tests, no failure recovery, handoff without runbook.

## 7. Job aid / carry-away

- Handoff package template with the five required contents and the test matrix.

## 8. Claims to establish and verify

- Every lab step must match the current Indexing API and connector tooling
- Test criteria that genuinely prove correctness
- Handoff requirements for a supportable connector

Freshness window: 90 days; re-verify after any API change.. Every factual sentence carries a `claim_id` resolving to `sources.json`.
