## 1. Narrative frame

- **Recurring persona:** Nia planning the quarterly cycle
- **Through-line situation:** A platform release lands and nobody checked what it changes for existing agents
- **Cold open (A1) hook:** The release notes were three lines long. Two of Nia's agents behave differently this morning.
- **Signature moment (one T3 reveal):** Release readiness checklist resolves: regression scope, enablement updates, and comms sequence in order

## 2. Learning outcomes (observable)

- `OBJ-01` — Assess a platform release for regression and enablement impact
- `OBJ-02` — Plan the regression checks a release requires
- `OBJ-03` — Update enablement material affected by a release
- `OBJ-04` — Sequence rollout communications

## 5. Interactions

- **`INT-SORT`** — Changes classified by whether they require regression testing.
- **`INT-SEQ`** — Sequence rollout communications.
- **`INT-BRANCH`** — Mid-quarter behavior-change response.
- **`INT-HOTSPOT`** — Release readiness cycle - the signature resolve.
- Keyboard-equivalent path required in every component; state persisted to `cmi.suspend_data`; restores exactly on resume.

## 6. Assessment plan

- **Format:** Checklist review, rubric-scored (tracker: `Checklist review`)
- **Blueprint:** Learner submits a release readiness checklist: impact assessment, regression scope with rationale, enablement updates identified, and a comms sequence.
- **Mastery:** 80%, retries reshuffled, explanatory feedback on final attempt
- **Distractor sources:** Embedded checks target: assuming no regression risk, updating comms before verifying behavior, ignoring enablement debt.

## 7. Job aid / carry-away

- Release readiness checklist with the regression scoping rule.

## 8. Claims to establish and verify

- How platform releases are communicated and what changes are typically included
- What regression testing is possible with available tooling - do not imply a harness that does not exist

Freshness window: 90 days (release process).. Every factual sentence carries a `claim_id` resolving to `sources.json`.
